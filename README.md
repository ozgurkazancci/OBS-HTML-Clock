# OBS HTML Clock
A simple, lightweight HTML clock overlay designed specifically for OBS Studio. Easily customize your time formats, background transparency, and style!

## ⚙️ How to Use in OBS Studio

Adding this clock to your stream is quick and easy:

1. Open OBS Studio and navigate to the **Sources** dock.
2. Click the **`+`** icon and select **Browser**.
3. Give your new source a name (e.g., "Stream Clock") and click **OK**.
4. In the properties window, check the box next to **Local file**.
5. Click **Browse** and select the HTML file from this repository.
6. Set the dimensions to fit the clock perfectly:
   * **Width:** `283`
   * **Height:** `50`
7. Click **OK** to save. 

*The clock will now appear on your canvas with a transparent background, ready to be positioned anywhere on your stream!*
